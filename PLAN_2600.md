## Log
- 2026-11-02, task 1+2: the mod is a 961-byte patch of the original cart; its generator keeps straight banks (docs/MOD_2600_SPEC.md). Captures in `assets/atari/river2600/`.
- 2026-11-02, task 4 (partly): `RIVER_2600` flag in `src/river.c` and `tools/river_model.py` (env `RIVER_2600=1`, or `RIVER_CART=` for the mod cart). `tests/host_river.ps1 -Mode2600` matches the model on 4 start levels. GBC build: `.\build_gbc.ps1 -River2600`.
- **First 2600 measurement (generator only, original tree/house art, no atlas):** fast 0.83 passes/frame (baseline 0.76), `river_update` avg 24.6k (was 33.9k), peak 98.7k (was 92.3k). The straight banks help only on average. The peaks sit in rows with features (templates: trees, houses, islands, bridge): `river_run_job` 41k, `convert_row` 18k, `generate_raw_row` 26k. A band lookup for plain rows would not touch them; the atlas has to cover the features.
- 2026-11-02, tasks 4-6: **blocky 2600 river** (decision: edges on an 8 px grid, ramps one 8 px step per 8 rows, no houses/trees, islands exact for now). Fast flight 0.76 -> **0.97** passes/frame at double speed, DMG proxy 0.37 -> **0.57**. Gates: X=1.00 and Y=0.60 are **not met yet** (close). What is left in the profile: `river_band_replay` (110k once per ~25 s of fast flight: narrow 8 px river and jumps above 16 px take the exact path), island rows (not exercised in the level-1 profile), `oam_camera` 9k per pass, the stripe write.
- 2026-11-02, review fixes: (1) the atlas reserved 96 slots and left the exact ring 154, below its measured peak of 182: the host check now flags uploads that overwrite a visible map cell (`clobbered`), found thousands, fixed with `RIVER_ATLAS_N` = 40 (210 ring slots, 0 clobbered over 20,000 rows x 4 levels). (2) `slot`/`dst` pointers in the new functions moved to file scope (AGENTS rule 3). (3) `host_river_fast.ps1 -JobCols 10` exercises the GBC's yield/resume; identical. (4) The right edge now rounds up and the left down (drawn river contains the true river, so the spawner's objects stand on water); irregular bands fell from ~1% to ~0.1%.
